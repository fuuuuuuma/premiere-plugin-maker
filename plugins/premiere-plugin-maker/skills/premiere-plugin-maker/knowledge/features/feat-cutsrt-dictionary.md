## 何をする機能か

音声認識は人名や社名、専門用語をよく間違えます。「毎回同じ直しをする」手間を減らすために、**誤→正の置換表（辞書）**を持ち、字幕を作るたびに適用します。

辞書は 2 通りで育ちます。(1) 利用者が手で追加する。(2) **差分学習**: 利用者がテロップを手直しした後、「自動で作った字幕」と「直した後のテロップ」の違いを比べ、直された言葉を辞書の候補にする。候補は一覧に出て、承認（個別・まとめて）か却下を選びます。承認したものだけが辞書に入ります。導入時には、ありがちな間違いを集めた初期の辞書を追加専用で取り込みます。AI から使うための MCP の道具（`premiere_learn_dictionary`・`premiere_dictionary`）もあります。

## 作り方

1. パネルが、いまのシーケンスをタイムラインの交換形式（OTIO）で書き出す。
2. サーバーが OTIO の中のテロップの本文を読み取る（テロップは Premiere 独自のバイナリの中に本文がある）。
3. 同じ区間の、自動で生成した字幕と比べ、違う所を語や句の単位で対応づけて候補を作る。
4. 候補を絞る規則を通す（下の「置換だけ」）。
5. 候補は一覧に出す。承認で辞書へ、却下で候補から消す。
6. 字幕の生成のときに、辞書の置換を適用する。さらに、辞書の語に複数の意味がある場合の判定を言語モデルで補う処理があり、文字起こしと並行に走らせて待ち時間を隠す。

## 使った API と道具

- UXP: `ProjectConverter.exportAsOpenTimelineIO`（OTIO の書き出し）。
- サーバー: OTIO の解析、バイナリからの本文の取り出し、差分の対応づけ、辞書の保存（設定フォルダの JSON）。ルートは `/dictionary`・`/dictionary/approve`・`/dictionary/reject`・`/dictionary/learn`・`/dictionary/import` など。
- 一覧の画面は UXP の制約（行の押しつぶし）に注意（`feat-cutsrt-split-fix` と共通）。

## つまずきと直し方

- **辞書には「置換」しか入れられない**。差分学習が「大 → 徳大」のような**挿入**を候補にした。語の対応としては正しい（「大セミナー」→「徳大セミナー」）が、辞書は全文置換に使うので、承認すると「大変」が「徳大変」に、「拡大」が「拡徳大」になる。「クロード → クロードコード」も、適用すると「クロードコードコード」に伸びる。→ 候補のペアで**片方がもう片方を部分文字列として含むものは弾く**。大小文字だけの違い（gpt → GPT）は含有にならないので通す。
- **同じ編集が、規則側は語で、AI 側は句で二重に登録される**（「大 → 徳大」と「大セミナー企画 → 徳大セミナー企画」）。→ 含有関係で 1 つに畳み、狭い方だけ残す。
- **辞書は誤字修正表ではなく、音声認識が知らない固有名詞の覚え書き**。同音異表記（名字の漢字違いなど）は誤字かどうかで切らず拾う。
- **本文の読み取りが数週間ずっと 0 件だった**。テロップの本文は Premiere のバイナリの中に「4 バイトの長さ＋UTF-8 の文字列」の形で入っているため、これを走査して推定していた。規則を「最長」から「先頭に最も近い位置」へ変えたところ、アニメーション付きのテロップで、本文より前にある内部のプロパティ名（`AnimationType`）を拾ってしまった。→ 実物の中身には、本文のほかにプロパティ名・制御文字・書体名が同居していた。位置や大きさでは決まらないので、**中身で決める**（日本語を含む > 空白や句読点を持つ > 英数字 1 語のプロパティ名は除外）。
- **仕様が公開されていないバイナリの規則は、実物を 1 件でも手に入れてから変える**。試験用のダミーだけを根拠に変えない。診断のために、本文が読めないときは実物のバイナリを診断ログに保存する。保存を後回しにしたため、推測で直すたびに別の文字列が出る往復を 3 回した。
- **辞書の一覧の行が押しつぶされる**。UXP は並びの中の行を、中身より小さく縮める。→ `flex: 0 0 auto` で縮めない（`core-ui-rules`）。
- **語義の補助判定を直列で走らせると初回が遅い**。→ 文字起こしと並行に走らせ、改行の工程の直前で待ち合わせた。

## 結果と今の状態

- 差分学習・承認・置換の適用は実機で動いている（本文の読み取りの修正は 2026-08-16）。
- 置換だけを登録する規則と、含有・重複を畳む処理は自動テストで固定済み。
- アニメーション付き以外の特殊なテロップ（複数の書体の混在など）での読み取りは、実物が増えたときに確かめ直す。
