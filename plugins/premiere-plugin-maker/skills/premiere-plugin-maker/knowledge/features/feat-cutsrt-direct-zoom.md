## 何をする機能か

演出タブの機能の 1 つです。タイムライン上の見本のコマに四角をドラッグして囲み、「ここにズームして」と頼むと、その四角が画面の中央いっぱいになるまで拡大する動きがクリップに付きます。説明動画で「この部分を見てください」と寄りたいときの手間を減らします。

## 作り方

1. **見本のコマを出す**: 再生ヘッド位置のコマを `exportSequenceFrame` で一時フォルダへ PNG に書き出し、サーバーが画像の中身を `data:` の形に直してパネルへ返す。パネルは `<img>` で表示する（UXP は動画の再生も複雑な描画も当てにならないため、静止画で出す）。
2. **四角を囲む**: 画像の上でドラッグして四角を作る。四隅のつまみは「反対側の角を固定して縦横比を保ったまま」大きさを変え、内側のドラッグで四角全体を動かす。
3. **位置と拡大率を計算する**: 四角の中心をシーケンスの中央へ寄せ、拡大率は四角が画面を満たす倍率にする。拡大した結果が画面の外へはみ出さないように、**四角が端に近いときは内側へ寄せて**画面の端を見せない。
4. **動きをキーに焼く**: 「なめらか」に動かす場合は、補間の曲線に頼らず、**1 コマごとの直線のキーフレーム**として位置と拡大率に書き込む。1 つの取引で付けるので取り消しは 1 回。

## 使った API と道具

- UXP: `Exporter.exportSequenceFrame`、クリップのモーション（位置・スケール）へのキー追加（`createSetTimeVaryingAction`・`createAddKeyframeAction` など）。
- 焼き込みの考え方は `ref-keyframe-interpolation`。同じ取引で補間の種類を変えられない制約があるため、曲線の代わりに細かい直線にする。

## つまずきと直し方

- **コマの書き出しが完了前に返る**。「一時フォルダの外」という誤解を招くエラーが出た。→ サーバー側で書き終わるまで最大 15 秒待つ（`feat-cutsrt-direct-stamp` と共通）。
- **つまみの位置が取れない**。UXP では `dataset` が空のことがあるので、`getAttribute` で読む。
- **ズームした結果が画面外を映す**。→ 端に近い四角は内側に寄せる。
- **付けたキーの範囲外に余計なキーが残る**。キーを打つために時間変化を有効にすると、再生ヘッドが 0 のとき時刻 0 に余分なキーが増える（`core-transactions` の T5）。→ 範囲の外のキーは範囲指定で消す。
- 「四角にぴったり寄る」を既定に変えた直後は、実機でまだ見ていない。

## 結果と今の状態

- 実機で、四角を囲む・四隅のつまみで大きさを変える・内側ドラッグで動かすところまで確認済み。
- 未確認: 「四角にぴったり寄る」を既定にした後の動き、複数クリップにまたがる場合、取り消しで元の状態に戻ること。
