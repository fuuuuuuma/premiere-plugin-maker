## 何をする機能か

見本にしたクリップの「効果の状態」を 5 個の棚（スロット）に写し取り（キャプチャ）、別のクリップを選んでワンキーで同じ状態にする小さなパネルです。モーション（位置・拡大縮小・回転）、不透明度、そして後から足した効果の全部の設定値が対象です。

この記録は、小型の単体プラグインとしての作りです。のちに Cut & SRT の「エフェクト」タブに取り込まれました（`feat-cutsrt-fx-slots`）。

## 作り方

- 構成は最小の 5 点に、ショートカット用のコマンドが 5 個。画面は、5 枚のカード（見出し、保存した内容の表示、キャプチャ・適用・消去の 3 つのボタン）と、折りたたみのログ。カードには「キーボードショートカットに割り当てる」と薄い注記を出す。
- **保存の中身**: 棚ごとに、効果の一覧。各効果は、内部名・表示名・「固定の効果か」・設定項目の一覧（番号・名前・値・値の種類）。
- **永続化**: `localStorage` に、素の値だけを書く。座標のような Premiere のオブジェクト（`PointF`）は、そのままでは JSON に載らないので、`[x, y]` の配列に畳んで保存し、適用のときに `PointF` に戻す。
- **固定の効果**（モーションと不透明度）は、最初からクリップに付いているので、既存の部品の設定項目を書き換える。それ以外の効果は、新しく作って足す。
- **値のセット**: 値は `createKeyframe(値)` と `createAddKeyframeAction` で入れる。時刻の指定は無く、「その値にする」ことだけを行う。

### 取引の 3 段階（適用の流れ）

効果の適用は、次の 3 段階で行います（2026-07-06 に、この形に作り直しました）。

1. **取引の外（非同期でよい）**: 内部名の読み取り、`VideoFilterFactory.createComponent(内部名)` による部品の生成を済ませる。
2. **取引の中（同期だけ）**: `lockedAccess` の中の `executeTransaction` で、アクションを作って足す。固定の効果の値、足す効果の追加（`createAppendComponentAction`）が対象。取り消しは 1 回。
3. **別の取引**: 足した効果を、後ろから内部名で探して取り直し、設定項目に値を入れる。足す前の部品は設定項目を持たないため。

## 使った API と道具

- `VideoFilterFactory.createComponent`、`chain.createAppendComponentAction`、設定項目の値を作るアクション、`PointF`。
- `project.lockedAccess`、`project.executeTransaction`。
- 選択の取得は `sequence.getSelection()`（映像クリップだけに絞る）。

## つまずきと直し方

この小型版には、独立した実機のログや引き継ぎ文書がありません。分かっているのは、コードのコメントと、2026-07-06 の修正の趣旨です。

- **非同期の解決を取引の中に混ぜると、「無効なオブジェクト」で落ちる**。→ 3 段階に分ける。
- **足した効果にすぐ値を入れようとして失敗する**。→ 取引を分け、取り直してから入れる。取り消しは 2 回になる。
- **座標の保存で、JSON にならない**。→ `[x, y]` に畳む。
- **「固定の効果」かどうかの判定が、表示言語に左右される**。コードは、内部名に Motion・Opacity を含むか、表示名が日本語と英語のどちらかに一致するか、で判定している。→ 他の言語の UI は考慮されていない。内部名で判定する方が安全（推測）。
- **版の数字が合わない**。manifest は 1.0.0 のまま、コードの冒頭は「v4」。→ 同じ定数から出す。

### 記録が食い違う所

| 話題 | 記録 A | 記録 B | キットの部品が合わせた側 |
|---|---|---|---|
| 「キーフレームを打つ」とは | このプラグインは、値のセット（時刻なし）だけ | アニメーションのキーは、時刻つきで、別の拡張（`feat-ed-motion`）で実装されている | キーの打ち方は `feat-ed-motion` と部品 `motion-bake` に合わせる。このプラグインには、時刻つきのキーが無い |
| アクションを取引の外で作ってよいか | 作者の実測の正典は「中で作る」 | 無音カットの小型プラグインは、外で作っても動いた例がある | 「中で作る」を既定にする（`core-transactions`、詳細は `feat-clip-clipboard`） |
| 補間（イーズ）の扱い | — | 同じ取引では補間を変えられない | 補間は焼き込みで再現する（`ref-keyframe-interpolation`） |
