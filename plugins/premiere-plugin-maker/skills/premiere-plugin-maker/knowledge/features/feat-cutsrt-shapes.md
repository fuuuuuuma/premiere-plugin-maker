## 何をする機能か

UXP には「図形（四角・円・多角形）を作る」API がありません。Cut & SRT は、**Premiere に同梱の図形入りの MOGRT をひな形（ドナー）にして、中のバイナリを書き換え、図形の色・大きさ・形を変えた MOGRT を作って挿入する**方式を試しました。帯のテロップ（長方形＋文字）、ワイプ用の真円、3〜24 角の多角形を作り、**挿入したあとも Essential Graphics で色や大きさを再編集できる**のが狙いでした（PNG 画像を貼る代替案との決定的な違い）。

**今は凍結しています。パネルからは使えず、サーバー側のコードだけ残しています。** この記録は「何を試し、何が分かり、なぜ止めたか」です。同じ道に入る前の参考にしてください。

## 作り方

- **ドナー**: Premiere の「Graphic Overlays」の同梱 MOGRT（文字と図形の 2 層の構成）。場所は実行時に探し、環境変数で差し替えられる。
- **MOGRT の中身**: MOGRT は zip（`definition.json`、言語ごとの `project*.prgraphic`、サムネイル）。`.prgraphic` も zip で、中に gzip 圧縮した XML がある（`ref-mogrt`）。
- **書き換える所**: 3 つの任意値のパラメータ（文字・見た目・パス）の開始キーフレームの値（base64 のバイナリ）。
  - 文字: 長さ＋UTF-16LE の JSON（本文・サイズ・色・揃え）。揃えの数値は 0=左・1=右・2=中央（最初は「1=中央」と書いた誤りがあった）。
  - 見た目: 同じ形式の JSON（色は R + G×256 + B×65536 の整数）。
  - パス: 版・点の数・各点（種別・頂点・入出のハンドル）・閉じるかどうか。真円はベジェ曲線の係数 0.5522847 で近似。
- 末尾の検証値（BinaryHash）は、先頭 24 桁の計算規則が非公開なので、新しいデータの md5 の先頭で代用した。
- **全言語の `.prgraphic` に同じ書き換えを行う**（日本語の画面は日本語版の `.prgraphic` を読むため）。識別子を新しい UUID に振り直す。
- 挿入は `SequenceEditor.insertMogrtFromPath`（公式）を使う。

## 使った API と道具

- サーバー側で zip／gzip／base64 の処理と XML の書き換え（`shape_mogrt.py`）。
- UXP: `insertMogrtFromPath`（Action を返さない独立した呼び出しで、取引に入れられない）。
- 診断ラダー: 無改変のコピー（0 番）から段階的に書き換えを足して挿入し、どの段階から空になるかを切り分ける試験の一式。

## つまずきと直し方

- **挿入しても中身が空のグラフィック**になる。最初の診断は「キーフレームが空タグで不透明度が 0 に評価される」だったが、**これは誤診**だった。位置の座標系やアンカーの扱いの誤り、キーフレーム処理（空タグを残す静止化）の誤りも重なっていた。→ キーフレーム要素を削除して、時間変化なしにする静止化に直し、座標系を直した。それでも実機では空のままだった。
- **同じトラックに 2 つ目を入れると 1 つ目が消える**。→ 言語別 `.prgraphic` のシーケンス識別子の同期（修正）。
- **「空グラフィック」という一語で別の病気を同じ名前で呼んでいた**。症状を細かく分け、原因ごとに切り分けること。
- **第 4 ラウンドは、修正を足すのをやめた**: 暗黙の前提 6 項目（ドナーそのままで入るか、など）を 1 つずつ実測で潰し、残る容疑を検証値（BinaryHash）の 1 点に絞った。確定はしていない。
- **打ち切りの判断**: 3 ラウンド（修正の版を 3 つ）かけても、実機は空のままで、競合の調査でも別の方式（CEP 側）に突破口が無いと分かったため、パネルから外した。
- **凍結のやり方**: パネルから到達できなくして、サーバー側のコードとテストと診断ツールは**残す**（消さない）。サーバーが起動時にその部品を import しているので、消す・配布から外すとサーバー自体が起動しない。「撤去されたことを守る」テストを足し、復活の手順（画面・関数・テスト・ガイドの 4 段）を記録に残した。
- **外部の製品名を配布物に出さない**（機能名の独自化）。

## 結果と今の状態

- 実機では、図形が描かれた MOGRT を挿入できていない。理由は確定していない（検証値の規則が非公開のため、Premiere が改変を弾いている疑いが濃い、という位置づけ）。
- 動くようになったという記録はない。図形が必要なときの代わりは、PNG 画像を貼る、Premiere の図形ツールで作ったものを MOGRT に保存して使う、などになる。
- 復活させる場合は、まず無改変のドナーが入るか（0 番）から実機で切り分ける。
