## 何をする機能か

会話動画で、テロップを「話した人ごと」の別トラックに振り分けます。たとえば演者の発言は V2、聞き手の発言は V3 のように並べ替えます。色分けやレイアウトを話者ごとに変えたいときの下ごしらえです。

「必ず決める」方式です。迷った所を保留にして元のトラックに残すと、「演者と誤判定された」ように見えてしまったので、全部のテロップに答えを出し、**自信が低い所にだけ目印のマーカー（「話者を確認」）を付けて**人が見直せるようにしました。

## 作り方

判定はサーバー（Python）で行い、パネルは「どのテロップが誰か」の表を受け取ってトラックを動かすだけです。Premiere の操作は UXP 側、重い音声処理はサーバー側という分担です。

判定は次の材料を合成します。

1. **声紋**: 音声から話者の特徴（声紋）を取り出し、テロップの区間ごとに比べる。冒頭の話者がはっきりしている区間は、それを優先する。重なって聞こえる区間は信頼を下げる。
2. **声の分離**: 2 人が同時に話している区間は、音声を話者ごとの声に分離する。分離した各声に文字起こしを当て、**テロップの本文を話している声はどれか**を採点し、その声の声紋を使う。
3. **言語モデルへの質問（任意）**: 本文だけを見せて「直前の発言と別の人か」を 1 本ずつ聞く。設定が空なら何も送らず、声だけで判定する。
4. **前後の合成**: 前から後ろへ、後ろから前への両方向で確率をなめらかに合成して、1 本ずつの判断のぶれを減らす。
5. **確からしさ**: 合成後の確率が 0.9 未満のテロップに、マーカー「話者を確認」を付ける。

実行中にタイムラインが変わっていないかは、解析の前と実行の直前でクリップ配置のスナップショットを比べ、変わっていたら止めます。判定の記録は「判定ログをコピー」ボタンとサーバー側のフォルダに残り、あとから見直せます。

## 使った API と道具

- Premiere 側: シーケンスのテロップ（グラフィックのクリップ）の一覧、トラック間の移動、マーカーの追加（`premierepro` の取引つきの操作）。
- サーバー側: 音声の取り出しは ffmpeg、声紋は TitaNet 系のモデル、声の分離は MossFormer2 系のモデル、本文の確かめは Whisper 系の文字起こし。Apple シリコンの Mac では GPU で動かし、1 区間約 1 秒で済みました（ライブラリ経由は約 14 秒）。
- 配布の範囲: 分離のモデルと GPU 用ライブラリは Apple シリコンの Mac だけに同梱。Intel の Mac と Windows は分離なしの方式（声紋と文脈だけ）で動かす縮退構成です。

## つまずきと直し方

- **保留が多く、元のトラックに残って誤判定に見えた**（保留 19/52 本など）。→ 「必ず決める」方式に変え、自信が低い所はマーカーで人に渡す形にした。
- **同時に鳴る別の声が声紋を引っ張る**。別の人の相づちが重なる区間で、混ざった声紋が間違った方へ寄った。→ 声を分離し、各声に本文を当てて「本文を話す声」の声紋を使う。重なりのある 38 本が全問正解になった。
- **映像の口の動きで話者を探す方式は不採用**。単独の発話では精度が出る（AUC 0.93〜0.98）が、重なりでは効かなかった。
- **言語モデルに頼り切ると「直前と別の人」を取り違える**。実測で食い違いが出た 1 本は、声が正しく、言語モデルの方が外れていた。→ 言語モデルは材料の 1 つに留め、必須にしない（未設定でもエラー停止しない。最初の版では必須でエラー停止していたのを直した）。
- **外部の言語モデルを使うときの注意**: 本文を外部サービスへ送ることになる。送信先・料金・利用規約は利用者が確認し、設定が空なら何も送らない既定にする。鍵はファイルに書かず OS の保管庫に置く。
- **他のサービスの音声処理ライブラリを丸ごと使うと遅い**。モデル本体を直接動かす形にして 14 秒を 1 秒に縮めた。モデルの重みの使用条件はコードのライセンスと別なので、同梱の前に必ず確認する。

## 結果と今の状態

- 実機（Premiere）で 2 回実行し、2 回とも 52/52 本が正解。要確認のマーカーが付いたのは 1 本だけで、その 1 本も判定自体は正しかった。
- 製品コードでの回帰評価は、全体 390 本で 390/390。外れが出るときも自信が低い側に出るため、全部マーカー付きになる。
- 分離なしの縮退構成の実測は 386/390（印 34 本）。Apple シリコンで分離ありは 389〜390/390（印 25 本）。
- Windows と Intel の Mac での実機確認は未実施。
- 評価に使った素材は、話者が正しく分かっている撮影素材だけ。別の撮影条件（マイクが 1 本、BGM が大きいなど）での精度は未確認です。
