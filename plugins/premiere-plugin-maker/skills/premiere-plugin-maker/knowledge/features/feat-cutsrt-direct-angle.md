## 何をする機能か

演出タブの機能の 1 つです。選んだクリップの映像を、「もう少し引いた画角」「斜めから」などの指示で別の画角に作り変え、**結果の映像を元クリップの真上のトラックに置きます**（音声は外します）。撮り直さずに画のバリエーションが欲しいときに使います。

これは**外部の生成サービスにお金を払って動く機能**です。ほかの機能と違い、映像が自分のパソコンの外へ出て、費用が発生します。

## 作り方

1. **サービスと道を選ぶ**: 動画生成サービス（Higgsfield）の動画編集モード（Seedance 2.5 の video-edit）を使う。呼び出しの道は 2 つ用意した。
   - **公式 CLI（既定）**: 利用者が自分のアカウントでログイン済みの CLI を、サーバーが子プロセスとして呼ぶ。**契約中のプランのクレジット**を使う。
   - **公開 API（選択肢として残置）**: 鍵を OS の保管庫（Mac はキーチェーン、Windows は DPAPI）に置いて呼ぶ。こちらは Web のサブスクとは別の前払い残高を使う。
2. **見積もりを先に出す**: 生成の前に費用を計算して画面に出し、利用者が許可したときだけ実行する。CLI には「実行前に金額だけ聞く」命令があるので、**利用者の映像は送らず、同じ長さの黒い試験映像**で見積もりを取る。
3. **生成する**: CLI の `generate create` で投入し、`generate get` で完了を待ち、結果の動画の URL から受け取る。受け取った映像から音声を外し、元クリップの真上のトラックへ置く。

## 使った API と道具

- 公式 CLI（MIT ライセンス）。Mac では Homebrew で入る。
- サーバー: 子プロセスの起動、結果のダウンロード、音声を外す処理（ffmpeg）。
- パネル（UXP）: 見積もりの表示、許可の確認、`insertProjectItem` 系の配置。
- 鍵: OS の保管庫に保存。`GET` は「保存済みかどうか」だけ返し、値は返さない。ファイルに平文で書かない。

## つまずきと直し方

- **費用と規約（最重要）**:
  - 利用するたびにクレジット（またはお金）が減る。実測の目安は、720p で 5 秒 38 クレジット、10 秒 75、7.3 秒 55、1080p の 5 秒で 60 クレジット。公開 API は入力と出力の秒数で課金され、720p で 1 秒あたり約 0.28 ドルだった（2026-10 時点の実測。料金は変わるので毎回見積もりを取り直す）。
  - **公開 API の残高は Web のサブスクとは別**（公式の説明）。サブスクがあっても API は動かない、または別に課金される。どの道で課金されるかを画面に出す。
  - 映像を外部へ送る前に、**利用者が送信先の利用規約・生成物の権利・出演者や素材の権利（肖像・第三者の素材）を確認する**。このキットは規約の中身を保証しない。最初の実行は、見積もりと「映像が外部へ送られる」ことを見せて許可を取る。
  - **鍵やアカウントの情報を記録・コミットに入れない**。
- **CLI の名前が別のコマンドと衝突する**。短い名前（`hf`）が機械学習の公開サイトの CLI と同じため、Homebrew がリンクを張らない。→ インストール先の実行ファイルを直接指定する。
- **CLI に取り消しが無い**。投入したら止められない。→ 投入の前の確認を厳しくする。
- **見積もりに画角の指定を送り忘れた**。→ 見積もりにも生成と同じ指定を渡す。
- **受付番号を応答から取れない**。応答の形が想定と違った。→ 一覧を引いて受付番号を拾う処理を足した。
- **鍵の保管を任せた担当が、本物のキーチェーンに試験の項目を残した**。作成後の確認で「保存済み」と誤表示しかけた。→ 秘密の保管を扱う作業を任せるときは、本物の保管庫に書かず、使い捨てのキーチェーンだけで試すよう指示する。作業後は保管庫の項目の属性（作成日時）を確認する（値は読まない）。
- **配布物から鍵の部品が落ちた**。名前に `secret` を含むファイルは配布ビルドが自動で外す。→ 部品名を `keychain_store` に変えた（`feat-cutsrt-install-update` を参照）。

## 結果と今の状態

- 実機で、生成と受け取りまで確認済み（480p・約 4 秒で 14 クレジット）。
- 未確認: 真上のトラックへの自動配置、取り消し、1080p の品質、別の画角指示の効き方。
- 最初の実行は、見積もりを見せて許可を取る約束で運用する。
