## 何をする機能か

パネルに並ぶ「デザイン」と「アニメ」のカードと、その見本（静止画と短い動画）を作る仕組みです。利用者は見本を見て、1 クリックで当てるものを選びます。見本が本物と違うと信用を失うので、**見本は描き直さず、本物の Premiere で作ったものを使います**。

## 作り方

### カタログの構造

- デザイン: `catalog/design/<系列>/<id>/style.json`、アニメ: `catalog/motion/<系列>/<id>/motion.json`、系列ごとに `series.json`。データだけで、何も実行しない。
- カードは、系列で分類し、検索できる。パネルは、広くて低い置き方でも、幅 316 ピクセルほどの狭い置き方でも崩れないようにした。

### 見本の作り方

1. 専用の空のプロジェクト（`ED_previews`）の専用シーケンス（1280×720、青灰の背景）に、デザインまたはアニメを組む。
2. `exportAsMediaDirect` で 3 秒の映像を書き出す（書き出し自体は同期で戻る。1 件の作成は全体で約 10 秒）。
3. ffmpeg で、静止画（`poster.jpg`）と短い動画（`preview.mp4`）に仕上げる。
4. 静止画は、候補の時刻のうち**いちばん明るい 1 コマ**を、ffmpeg の `signalstats`（輝度の平均）で選ぶ。
5. 軌跡が分かるアニメには、重ね描きの静止画（`trail.jpg`）も作る。

### 安全装置

利用者のプロジェクトを汚さないための決まりです。前面のプロジェクト名が `ED_previews` で始まらなければ何もしない。前面のシーケンスが専用のもの以外なら触らない。背景以外が入った V1 は伸び縮みさせない。置いた MOGRT は最後に必ず取り除く。保存はしない。

### 目視の確認

見本ができたら、書き出したフレームを自分の目で見て判定します。アニメは書き出した映像を 1/8 秒ごとに抜き、24 コマの一覧にして、全部を見ます。その際、**プレイヘッドを対象の時刻に置いてから書き出す**（置かないと、上のトラックのグラフィックが書き出しから落ちることがあった。原因は未特定）。

### 品質の門と、失敗の扱い

- デザイン: 塗りと「いちばん内側の線」の明暗差、縁の合計の太さ、影の不透明度、禁則（白文字に何も付けない、同じ太さの線を 3 本以上、ぼかし 0 で距離だけ大きい影）、書体の字形の有無。
- 検査の命令は、**どんな入力でも標準出力は JSON 1 行、終了コードは常に 0**。不合格は JSON の中の errors で伝える。

## 使った API と道具

- ExtendScript: `exportAsMediaDirect(出力, 書き出し設定, 1)`、`importFiles`、`overwriteClip`、クリップの `end`。
- ffmpeg（`signalstats`、トリミング、黒の余白付けによる縦横比の保持）。
- Python: 標準ライブラリ。検査の本体と、書体の検出。
- パネル側: 見本の絵を CSS と SVG で描く場面では、文字全体の見た目の寸法は「スタイルの値 × 0.78」（1080p の画素比）、詰め組みは `font-feature-settings: 'palt'`。縁の線の幅は「輪郭を中心にした線の全幅」で、外へ出るのは半分。

## つまずきと直し方

- **検査に落ちた項目が 1 つでもあると、カタログが永久に空になる**。初回に必ず踏む（同梱デザインの書体を持たない人が多いため）。検査の命令が失敗の終了コードを返し、同期の呼び出しが例外を投げていた。→ 命令は常に終了コード 0 にし、不合格は本文で伝える。例外の捕まえ方も、1 項目ごとに分ける。引数の羅列のようなエラー文は利用者に出さず、日本語の一文にする。
- **カードが真っ白（上半分しか見えない）**。CSS の grid で自動行の高さが 0 まで縮められ、`overflow:hidden` のカードが 8 枚で 101 ピクセルほどに潰れた。→ `grid-auto-rows: max-content`。3〜5 枚のうちは収まっていて気づけなかった。
- **見本の静止画が真っ暗**（点滅するデザイン）。固定の時刻で 1 コマを取っていた。→ いちばん明るいコマを選ぶ。
- **書き出しが出点を含まず、89 コマ（2.97 秒）で 3 秒に届かない／縦長の画像を引き伸ばして歪む**。→ 2.95 秒以上で通す。縦横比を保って黒で余白を足す。
- **書体が無いデザインを隠すと、画面が空になる**。同梱 100 種のうち 55 種が、Adobe Fonts の同期の欠落で消えた。→ 隠さず、「書体なし」の札を付けて別の書体で見本を出す（`feat-ed-import-styles`）。
- **狭いパネルで、検索と設定が画面外にはみ出す**。上の段が折り返さなかった。→ 折り返す。`vw`・`vh` は CEP では当てにならないので、幅と高さの分岐は JavaScript で body にクラスを付けて行う。
- **日本語入力の変換中の文字で、検索が 0 件になる**。→ 変換中は絞り込みを止め、確定で絞り込む。
- **Enter でカードの選択と適用が同時に走る**。→ Enter は選ぶだけ、Cmd+Enter で当てる。
- **ffmpeg が名前で見つからない**。CEP から呼ぶと PATH が最小。→ 候補の場所を順に試す。

### 記録が食い違う所

| 話題 | 記録 A | 記録 B | キットの部品が合わせた側 |
|---|---|---|---|
| 見本を UXP で動画として再生できるか | 設計時は「使えない」 | 後の調査では根拠も反証も確定できない | 未確認。見本は静止画を基本にする（`feat-cutsrt-design` は UXP 側で静止画の PNG を使う） |
| 見本の絵をパネル内で描くか | 初期の試作では、SVG でほぼ同じに描けた（40 種を目視で確認） | 設計の原則は「描き直し禁止」。本物とのずれは信用を失う | カードの静止画と動画は、本物の Premiere の書き出しを使う。SVG の描画はパネル内の補助として残っている（どこまで使うかは記録から確かめきれていない） |

## 結果と今の状態

- 画面と操作の作り直し（版 0.4.0）で、デザイン 19 件・アニメ 6 種を磨き直しました。見本の静止画は、最も明るい瞬間から選ぶようになっています。
- 見本の作り直しのうち、一部は未了のままです。
- 確かめていないこと: 英語など他言語の UI での見本の作成、Windows、速度を変えたクリップ。
- 作者向けの実機の作業は、専用プロジェクトに限り、V2 以上だけを使い、終わったら片付けて保存しない約束で行いました（`core-safety`）。
