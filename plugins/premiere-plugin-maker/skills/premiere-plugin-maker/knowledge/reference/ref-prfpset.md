## 仕様

.prfpset は、Premiere のエフェクトプリセット（効果の設定とキーフレームを丸ごと保存したファイル）です。中身は Premiere のプロジェクト XML と同じ流儀の XML です。

**木の構造**

```
Tree
└ BinTreeItem（Root）
   └ BinTreeItem「プリセット」（Properties に PresetsBin=1）
      └ 任意のビン（入れ物）の階層
         └ TreeItem
            └ FilterPresetItem
               └ FilterPreset
                  └ VideoFilterComponent（効果本体）
```

**FilterPreset の Type（キーをクリップのどこに合わせるか）**

| Type | 意味 |
|---|---|
| 0 | クリップ全体に引き伸ばす |
| 1 | イン点（クリップの頭）を基準にする |
| 2 | アウト点（クリップの終わり）を基準にする |

基準の位置は、1 秒 ＝ 254016000000 ticks の単位で書きます（`AnchorInPoint` の値が基準）。アウト点基準では、最後のキーを `AnchorOut` の 1 tick 手前に置く流儀です。

**キーフレームの書き方**

- 数値のパラメータ：`時刻,値,補間,0,in_x,in_y,out_x,out_y;` をキーの数だけ並べます。
- 補間の番号：0 ＝ リニア／3 ＝ イーズイン／4 ＝ イーズアウト／5 ＝ ベジェ／6 ＝ 停止（hold）。
- 点のパラメータ（位置など）：`時刻,x:y,…,5,4,0,0,0,0;`。位置は正規化した座標で、`0.5:0.5` が画面の中央です。
- **末尾の `5,4,a,b,c,d` の a〜d は空間の接線**（入り x,y／出 x,y、正規化座標）です。Premiere 自身が保存するプリセットは「隣のキーとの差の 1/6」などを書きます（利用者が保存した 37 本で確認）。0 を書くと経路は折れ線になり、ExtendScript で打ったときのような「行き過ぎが約 2 倍」は起きない想定ですが、実機では確かめていません。

**テロップの動きは「トランスフォーム」（`AE.ADBE Geometry2`）で組む**

クリップ自身のモーション設定を壊さず、シャッター角度で残像も出せるからです。ParameterID は次のとおりです。

| ID | 意味 | ID | 意味 |
|---|---|---|---|
| 1 | アンカー | 7 | 回転 |
| 2 | 位置 | 8 | 不透明度 |
| 3 | 高さ | 9 | コンポジションのシャッターを使う |
| 4 | 幅 | 10 | シャッター角度 |
| 5 | 歪曲 | 11 | 均一スケール |
| 6 | 歪曲軸 | 12 | サンプリング |

## 例

動きの設計図（イン・アウト・ループなど）から .prfpset を作るときの考え方：

- 時刻は 0 を頭にして並べ、アウトの動きは Type 2 に切り替える。
- 動きの値は「現在の見た目を基準にした差分」にしておく（中央固定にしない）。右上に置いたテロップも、その場所のまま動く。
- 位置のキーを含むプリセットは、Premiere が書く形に合わせて接線も書く。

## 注意

- **アンカーの罠**：トランスフォームの拡大・回転は、既定ではアンカー（画面の中央 `0.5:0.5`）を軸に動きます。下のほうに置いたテロップに拡大系を当てると、中央から寄ってくる動きが混ざります。位置のキーが無いプリセットなら、アンカーと位置を同じ値（テロップの中心）にそろえれば直ります。
- 「実機で .prfpset を Premiere に読み込んで確かめた」記録は限られています。木の構造・Type・補間の番号・接線は、Premiere 同梱のプリセットと利用者が保存したプリセットを読んで確かめた事実です。**キットの生成器で作った .prfpset を Premiere が読み込めることは、確かめていません。** 配るときは、利用者側で読み込めるかを 1 回見てもらいます。
- ExtendScript の QE DOM にはプリセットを当てるメソッドが無く、プログラムから .prfpset を直接当てることはできません。利用者がプリセットのパネルからドラッグして当てます。
- キーの補間を同じ取引の中で変えられない UXP では、プリセットでなく 1 コマごとの直線のキーに焼く方法もあります（ref-keyframe-interpolation）。
- 色の既定値や blob の話は ref-prtextstyle、見た目の話は ref-mogrt を見てください。

## 出どころ

- Premiere 2026 同梱のプリセットと、利用者が保存したプリセット 37 本を読んだ記録（2026-09-02、2026-09-23）
- テロップ用の生成ツール（別プラグイン）の設計と、Effect & Design の動きの設計（トランスフォームの ParameterID、アンカーの直し）
- キットの部品 motion-bake（`prfpset_build.py`）
