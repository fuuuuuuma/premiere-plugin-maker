## 要点

- UXP の API には、プラグイン作りで頼まれやすい操作の一部が無い。最初に表で確かめ、無いものは「Premiere の API に無いので、ツールではできません」と先に言う。
- 代わりの手は 5 つ。FCP XML の作り直し、CEP の補助、MOGRT、利用者の手作業、Claude の画面操作。
- 「こうすれば擬似的にできるはず」という未検証の抜け道を、動くと言わない。やるなら 1 つのクリップで試して結果を見てから。
- 2026 年 9 月時点の状況。Premiere の版が上がると表は変わるので、実装の前に診断ボタンで確かめる。

## 詳しく

### できない操作の表

| 頼まれた操作 | API の状況 | 代わりの手 |
|---|---|---|
| クリップを分割する（レーザー） | 無い。27.0 ベータで試作が見えるが未確定 | 無音・フィラーの除去が目的なら FCP XML を作り直して新しいシーケンスに出す。任意の位置は CEP の補助（QE DOM）か、利用者に Cmd/Ctrl+K を押してもらう |
| クリップを別のトラックへ移す | 無い。移動は同じトラック内の時間移動だけ | 1 回の取引で「トラックをずらした複製（createCloneTrackItemAction）」と「元を消す（createRemoveItemsAction）」を足す。Cut & SRT の話者タブが Mac の Premiere で使った（書き方は `feat-cutsrt-speaker` の「トラックへの移し方」）。Windows は未確認。動かした後に数と中身を読み直して確かめる |
| 再生速度・デュレーションを変える | 読み取りだけで書き込みは無い | 「速度変更は手動でお願いします」と伝える。尺だけなら開始・終了の変更で足りる |
| 字幕（キャプション）の本文を書き換える | 無い。字幕トラックを作る API も未提供 | 字幕は SRT ファイル側で直して読み込み直す。今ある字幕の直しは手動 |
| プログラムモニターの再生・停止 | 無い（ソースモニターだけ） | 再生ヘッドの位置は動かせる。再生は CEP の補助か、利用者にスペースキーを押してもらう |
| メニューのコマンドを実行する（ネスト・リンク解除など） | 無い | 画面操作（Claude のデスクトップ版のメニュー操作）か、手順を文章で案内 |
| トラックのターゲット（どのトラックが選ばれているか）を読む | 無い | 利用者に対象のトラックを聞く |
| 図形（長方形・楕円）を新しく作る | 無い（UXP も CEP も） | 用意した MOGRT を挿入する |
| マルチカム編集 | 無い | 手動 |
| テロップ（テキスト）の本文の読み取り | 値の取得が複合型で失敗する | FCP XML または OTIO に書き出して、中の本文を読む（`ref-fcp7-xml`） |
| クリップのリンクの解除 | 無い | 右クリックメニューで案内 |
| Premiere のキーボードショートカットへの割り当て | プラグインからは指定できない | メニューのコマンドとして出し、Mac はシステム設定のアプリのショートカットで割り当てる（`recipe-commands-shortcuts`） |

### 代わりの手の選び方

1. **FCP XML の作り直し**: Premiere からシーケンスを XML で書き出し、外のプログラムで加工して読み込み直す。無音カットのように、分割した結果がほしいときに使う。元のシーケンスは残り、新しいシーケンスができる。
2. **CEP の補助**: 画面を持たない小さな CEP 拡張を併載し、ExtendScript の QE DOM（非公式）で再生・停止・分割をする。期限つき（CEP は 2028-12 に既定で無効の予定）。分割は実機での確認が済んでいないので、使うときは断る。
3. **MOGRT**: 図形やテロップのデザインを、テンプレートファイル（.mogrt）にして挿入する。
4. **利用者の手作業**: メニュー位置とショートカットを添えて頼む。1 回に 1 つ。
5. **Claude の画面操作**: Claude のデスクトップ版でメニューを操作する。戻せる操作で試してから使い、利用者の作業を止めるので事前に断る。最後の手段。

### 伝え方

1. 最初に「この操作は Premiere の API に無いので、ツールでは実行できません」と言う。
2. 代わりが API でできるなら、手順を示す。手作業なら、メニュー位置とショートカットを添える。
3. 未検証の抜け道（クリップを複製して両端を切り詰めて擬似的に分割する等）は提案しない。エフェクトやキーフレームが片側で欠けるおそれがある。

## やってはいけないこと

- 無い API を「あるはず」と決めつけて実装に入ること。作る前に診断ボタンで確かめる。
- 公式の文書に載っていない関数（例: `Sequence.setInPoint`）を、動くと言い切ること。使うなら存在を確かめてから呼び、無ければ手順を案内する。
- CEP の補助や QE DOM を、期限や非公式であることを伝えずに勧めること。
- 画面操作で、同意なしに取り消せない操作をすること。

## 出どころ

- Cut & SRT の記録（UXP に無いと記録された操作と代替の一覧、再生ヘルパー）
- Premiere を AI から操作するキット（premiere-agent-kit）の「UXP に無い操作の逃げ道」の表（2026-09 時点）
- Adobe 公式の API リファレンスと、Adobe 担当者のフォーラム回答（razor 相当は未提供、字幕 API は構築中）
- Adobe 公式フォーラムの未提供 API の一覧（字幕トラックの作成、トラックのロックなど）
- 実機で確かめた範囲は再生・停止（Mac、2026-08）。分割は実機未確認
