## 症状

- 書き出した画像だけを使う見本では、今選んでいるテロップの文字で見本を出せなかった。
- 別の見本の画面では、書体 25 個のうち 21 個が代わりの書体に落ちていても、気づけなかった。

## 原因

「描き直さない」という設計は、同じフォントと規則で描けば、一致を実測で確かめられる。ブラウザの `document.fonts.check()` は、代わりの書体に落ちていても true を返すので、これだけでは判定できない。

## 直し方

パネルの中で SVG として描く。合わせる点は次のとおり。

1. Adobe Fonts の書体は、`FontFace(url)` で読み込む。
2. 文字全体を 0.78 倍にし、縁の幅は輪郭の中心から全幅にする。
3. `font-feature-settings:'palt'`（詰め組み）を指定する。
4. グラデーションの角度は、90 度が上から下。
5. 書体が適用されたかは、宣言した書体と既定の書体を canvas に描いて画素を比べる。
6. アニメーションの見本は、書き出した動画を使う。近似までしかできない。

## 再発防止

- 全件を見比べ続ける。
- 字形があるかは文字コード表（cmap）で、適用されたかは画素の比較で、判定する。
- 名前と実際の描画は、機械で突き合わせる。
