## 症状

- 通知（トースト）が 1 行に固定されて「…」で切れ、「元に戻すには Cmd+Z を N 回」が読めないまま、自動で消える。
- 札（ラベル）が横にスクロールするのに、続きがあるという手がかりが無い。
- 診断の画面に入ると、戻れない。
- フォーカスの見え方と角丸の基準が、ばらばら。

## 原因

記録には書かれていない。1 行に固定された作り、自動で消す作り、ページ遷移で開く診断画面、基準が 1 か所にまとまっていない作り、が推測される。

## 直し方

これは方針案で、実装の結果は記録されていない。

1. 通知は折り返しを許して全文を出す。成功は 4〜6 秒で消し、失敗は × を押すまで残す。
2. 札は `flex-wrap:wrap` で折り返す。
3. 診断はモーダルにして、閉じるボタンと Esc を付ける。
4. フォーカスは `:focus-visible{outline:2px solid var(--accent);outline-offset:2px}` に揃える。角丸は 16 / 10 / 999px の 3 種に統一する。

## 再発防止

- 「戻すには」の回数は、実際に測った取り消しの回数を表示する。
- 取り消しの案内は、省略しない。
