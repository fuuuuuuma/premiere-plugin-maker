## 症状

クリップの設定を保存して別のクリップへ貼る機能で、2 つの問題があった。

- 効果やクリップのコピーで、入点の 1 つの値しか保存されず、アニメーション（キーフレーム）が消える。
- 貼り付けの方法の 1 つ（素の ProjectItem を挿入する）では、元のクリップについていた効果が全部失われる。

## 原因

- 元の実装が、入点の値を 1 つだけ保存し、適用していた。
- ProjectItem（素材）を素のまま挿入すると、元の効果を引き継がない新しいクリップができる。クリップを複製（クローン）した場合は、Premiere が効果を引き継ぐ。

## 直し方

1. キーフレームは、時間で変化するかを調べ、キーの一覧を取り、各キーの「入点からの秒数・値・補間」を保存する。
2. 適用するときは、時間変化をオンにし、適用先の入点 + 秒数の位置にキーを足し、補間を設定する。位置を指定するキーの API が無い環境は、先頭の値だけに縮退し、ログに書く。
3. 素の挿入で貼ったときは、挿入したクリップを「トラックと開始位置の一致」で探し出し、保存しておいた効果をそこへ複写する。クローンの場合は引き継がれるので複写しない。

## 再発防止

- 値でなく「キーフレーム列 + 補間」を保存する。
- 複製の方法（クローン・素の挿入）ごとに後処理を分ける。
- 補間の設定が同じ取引で効かない件（uc-uxp-interp-same-transaction）に注意し、実機で確かめる。

## 出どころ

- Cut & SRT の引き継ぎ書（2026-07-19、v0.4.1）
- キーフレームの API は公式リファレンスで確かめただけで、実機での確認はまだ
