## 症状

配布 ZIP を一時フォルダに展開して `install.command` を試したところ、最後まで完走した。そのせいで、常駐の設定ファイル（plist）が一時フォルダを指すように上書きされ、再起動で一時フォルダが消えるとサーバーが起動しなくなった。

## 原因

インストーラは「保護フォルダにあるときだけ止まる」設計だったので、保護されていない一時フォルダでは、本番の登録を書き換えて完走した。「15 秒たっても登録まで進まないはず」という時間切れでの止め方の見積もりも、2 回目以降はキャッシュで速くなって外れた。

## 直し方

1. 本番の場所で、常駐の入れ直し用スクリプトをもう一度実行して戻す。
2. 設定ファイルの指す場所と、状態確認の応答の版数で戻ったことを確かめる。確認用コピーも同じ版数を返すので、応答の版数だけでは見分けられない。

## 再発防止

- 配布物の確認は、ダウンロードフォルダなどの保護フォルダに展開して、保護の検出で止まるところまでを見る（手順書に書く）。
- 副作用のあるスクリプトの途中確認は、時間切れで止めるのではなく、スクリプト自身の早期終了の条件を踏ませる。
