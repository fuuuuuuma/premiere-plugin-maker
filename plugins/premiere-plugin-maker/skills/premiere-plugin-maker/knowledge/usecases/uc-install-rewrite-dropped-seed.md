## 症状

初回のインストールで、初期辞書（AI 用語の補正）が投入されなくなった。8 つの版のあいだ、誰も気づかなかった。以前の設計でも、手動登録が 1 件でもあると、以後も初期辞書が届かなかった。

## 原因

インストーラを「事前確認 → 自動修復 → 再検証」の 3 段に作り替えたコミットで、辞書を受け取る口（`/dictionary/import`）へ POST する古い処理が、どの段にも引き継がれずに消えた。同じコミットで他の退行も 2 つ生まれた。投入が効いていることを確かめるテストが無かった。

## 直し方

1. 辞書を入れる専用のスクリプトを作り、3 段目（健康診断が OK になった後）から必ず呼ぶ。
2. 辞書の取り込み関数は「追加だけのマージ」にする（既存を優先し、何度やっても同じ結果）。失敗は理由を表示して、終了コード 0 にする。
3. Windows も同じ設計に揃える。画面の出力が変わったので、導入ガイドも実際の出力に合わせて直す。

## 再発防止

- 文字列の有無でなく、動作を見る回帰テストを置く。空き番号のポートで本物のサーバーを起動し、本物の bash と curl で叩く。確かめる項目は、空の辞書への投入・何度やっても同じ・既存を上書きしない・サーバー未起動。
- 大きな書き直しは分割コミットにする。補助の手順の効果は、書き直しの前から固定しておく。

## 出どころ

- Cut & SRT の引き継ぎ記録（2026-07-26 の書き直しから 07-28 の復元。3 段構成の実機での通しは未確認）
