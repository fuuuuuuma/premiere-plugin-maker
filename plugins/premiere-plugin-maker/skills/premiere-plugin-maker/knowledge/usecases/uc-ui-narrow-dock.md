## 症状

- 3 つの欄の横並びは、幅が狭いと潰れた。
- 「AI で作る」のカードで、入力欄が豆粒の大きさに潰れた（幅 280〜480px のすべて）。
- `width:100%` の主ボタンが入力欄を潰した件は、3 か所で起きた（効果音のページ、辞書の追加行、それに続く 3 か所目と推測される箇所）。

## 原因

ドックの幅が狭く、横並びが成り立たない。入力欄と主ボタンを同じ `.row` に置き、`.btn-primary` の `width:100%` が入力欄の幅を奪った。

## 直し方

1. 3 つの欄は、3 段に積み、`[− N +]` のステッパーにする。
2. タブバーと辞書の行は `flex-wrap` で折り返す。行は 4 カラム固定にし、チェックボックスは番号のカラム（`.split-no`、38px）に同居させる。
3. 入力欄・補助の操作・主ボタンは、行を分ける。

## 再発防止

- 320px の幅で実測し、重なりが 0 であることを確かめる。
- Premiere 26.3 と UDT で、処理ログの最後までスクロールできることも確かめる。
- 縦積みとタブの折り返しは実機で確認した。`width:100%` の修正後に、再び描画した結果の記録は無い。

## 出どころ

- Caption Align と Cut & SRT の記録（2026-04-29〜09-23、Premiere 26.3）
