## 症状

「動きません」とだけ来ると、環境・手順・エラーの全文が分からず、聞き返しで往復が増える。ログの置き場は分散している。作者の手元に実機の無い OS（Windows）では、再現もできない。

## 原因

環境の値が手元に集まる作りになっておらず、第三者向けの切り分けの手順書も無かった。

## 直し方

1. 設定画面に「サポートパックを保存」を置く。ZIP に入れるのは、版数・OS・診断の OK/NG・決まった形式のサーバーの運用イベントだけ。字幕の本文・辞書・設定・鍵・個人のパスは入れない。保存先と SHA-256 を表示する。
2. 「AI に聞くテンプレート」（困りごと・環境・エラー全文・試したこと）を用意する。
3. Windows のインストーラは、失敗時にログの末尾を表示して Enter 待ちにする。「つまずいた番号・画面・処理ログ」を回収する 6 項目のチェックリストを付ける。
4. 診断は、失敗した時だけでなく、毎回出る値を増やしておく。

## 再発防止

- 配布するなら、秘匿化した診断の ZIP、問い合わせテンプレート、切り分け表を最初から付ける。
- 「困ったとき」の表は、問い合わせが来るたびに足す（完了したかは未確認）。
