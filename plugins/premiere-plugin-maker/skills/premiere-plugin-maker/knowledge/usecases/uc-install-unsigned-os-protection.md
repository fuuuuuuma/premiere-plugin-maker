## 症状

- Mac でダブルクリックすると「マルウェアが含まれていないことを検証できない」と出る。
- ZIP で転送すると「適切なアクセス権限がない」と出る（実行権限の消失）。
- Windows で「WindowsによってPCが保護されました」と出る（SmartScreen）。
- ファイル転送サービス経由で展開すると、フォルダの構成が崩れる。再展開すると、名前に ` 2` が付いたフォルダができる。

## 原因

- ネットから受け取ったファイルには、隔離の印（quarantine）が付く。
- ZIP での転送で、スクリプトの実行権限が失われる。
- Windows は署名の無い実行ファイルに SmartScreen を出す。
- ` 2` は、アーカイブユーティリティの連番で、不具合ではない。構成が崩れる詳しい原因は、記録に無い。

## 直し方

1. 標準の手順を、ターミナルに `bash ` と打って、インストーラをドラッグする形にする。Windows は「詳細情報」→「実行」。
2. インストーラが展開の構成を検査し、崩れていたら止めて、エラーログの末尾を自動表示する。
3. ` 2` 付きのフォルダができたら、上書きして、インストーラを再実行する。仮想環境や設定はデータフォルダにあるので引き継がれる。

## 再発防止

- 配布 ZIP は、フォルダごと丸ごと圧縮するのが鉄則。
- 保護機能は、迂回でなく、正規の起動手順を標準にして案内する。
