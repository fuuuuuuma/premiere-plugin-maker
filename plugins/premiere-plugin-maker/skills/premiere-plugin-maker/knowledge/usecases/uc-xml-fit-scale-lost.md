## 症状

無音カットで作ったシーケンスで、映像の大きさが変わる。たとえば 3456x2234 の画面収録を 1080p のシーケンスに置いていたクリップが、原寸の大きさに戻る。

## 原因

「フレームサイズに合わせてスケール」（Scale to Frame Size）のフラグは、クリップ単位の暗黙の設定で、Premiere が書き出す FCP XML には保存されない。読み込むとフラグが無くなるので、原寸で表示される。

## 直し方

1. 無音カットの処理が、解像度が合わず、しかも明示のスケールを持たないクリップに、決まった式でフィット用のスケールを付ける。
2. 手動でスケールを設定してあるクリップには触れない。無効にするスイッチ（`--no-fit-scale`）も用意する。
3. キーフレームを持つクリップを分けるときは、キーフレームの `when` が指す時間の基準が実機で未確定なので、時間をずらし直さず、警告だけ出す。

## 再発防止

- 「フィットスケールを付けた XML を読み込んだときの見た目」を、実機で確かめる項目として残した。実際の変換では 4020 クリップに 48.3438% を付けることを確認したが、Premiere に読み込んだ後の見た目は未確認。
- XML の往復で失われる、クリップ単位の暗黙の設定は、ほかにもあるものとして調べる。
