## この型で作れるもの

「字幕の区切りを AI に判断させる」「選んだクリップの説明を AI に書かせる」のように、AI の力を借りるプラグインです。呼び方は 2 通りあります。

- **CLI を使う**: 利用者が自分のパソコンに入れ、自分のアカウントでログインした AI のコマンド（Claude Code・Codex など）を、サーバーが子プロセスとして呼ぶ。プラグインは鍵を持たない。料金は利用者のプランに乗る。
- **API を使う**: 利用者の API の鍵で、サーバーが各社の API を呼ぶ。鍵が要り、使った分だけ課金される。

どちらも、UXP のパネルから直接は呼ばず、**手元のサーバー（`recipe-local-server-heavy`）のジョブ**にします。

## 前提

- 雛形は `panel-server`、部品は `keychain` を足す。
- **外へ出る内容を先に決める。** CLI でも API でも、渡した文章や画像は各社のサービスに送られます。字幕の本文や素材のコマが対象なら、そのことを画面に書きます。送りたくない場合の選択肢（ローカルのモデル、または AI を使わない）も用意します。
- **お金がかかるか、どこにかかるかを先に調べる。** CLI は利用者のプランの枠を使い、API は別の前払いの残高を使うことがあります（同じサービスでも別勘定のことがある）。画面に「どちらの勘定で、いくらくらいか」を出します。
- 規約: 送り先の利用規約、生成物の権利、写っている人や第三者の素材の権利は、利用者が確かめるものです。キットは中身を保証しません。
- 鍵・トークン・アカウント情報を、ファイル・ログ・コミット・チャットに書きません。

## 手順

1. 作業フォルダと部品。

   ```
   python3 <SKILL>/scripts/new_plugin.py --template panel-server --name "AI Helper" --label "AI 連携"
   python3 <SKILL>/scripts/add_part.py keychain --project <作業フォルダ>
   ```

   Windows は `py -3`。既定の場所は Mac `~/PremierePlugins/AI Helper`、Windows `%USERPROFILE%\PremierePlugins\AI Helper` です。
2. **鍵（API を使う場合）は保管庫に置く。** `server/ppm_keychain.py` が、Mac はキーチェーン、Windows は DPAPI（ユーザーごとの暗号化）に保存します。
   - サーバー側では `set_secret(名前, 値)`・`get_secret(名前)`・`has_secret(名前)`・`delete_secret(名前)` を使う。鍵の名前は英小文字で始まる 32 字までの英小文字・数字・`_`・`-`。
   - 鍵を入れる入口は、**画面の入力欄**（保存したら欄を空にする）か、サーバー側の小さなスクリプト（`getpass` で隠して読む）にする。**コマンドの引数やチャットに鍵を載せない**（履歴やプロセス一覧に残るため）。
   - パネルに返すのは「保存済みかどうか」の真偽値だけ。値は返さない。ログとエラー文にも出さない。
   - 部品の名前や、鍵を扱うファイルの名前に `secret`・`token` を入れない。配布の検査で自動的に外れ、配った先でサーバーが起動しなくなります（`uc-install-secret-name-dropped`）。
3. **CLI を呼ぶジョブ**（`server/jobs/<名前>.py`）の約束:
   - 依頼文は**標準入力かファイル**で渡す。引数に載せると、長い日本語が壊れる（特に Windows）。
   - 作業フォルダは空のフォルダにする（大きなフォルダを読みに行って終わらなくなる）。
   - **時間切れを決める**（実測に基づく値。他のプラグインの値を流用しない）。時間切れは子プロセスをグループごと止める。同時に走らせるのは 1 本にする。
   - 応答は決まった形（JSON など）で受け取り、壊れていたら 1 回だけやり直す。
   - 失敗は、利用上限・レート制限・認証切れ・時間切れに分けて、短い日本語にする。CLI の生のエラー文を、そのまま画面に出さない。
   - 常駐のサーバーは PATH が最小なので、ターミナルで動く CLI が「見つかりません」になることがある。探す場所を OS ごとに持つ。
   - 「CLI が見つかる」と「使える（ログイン済み）」は別。短い質問を実際に投げて確かめる（本番と同じ経路で）。上限（約 18 秒）を設ける。
4. **料金の確認と同意を、パネルの流れに入れる。**
   - 実行の前に、見積もり（わかる範囲で）と「送られるもの」を画面に出し、**利用者が［実行］を押したときだけ**動く。初回は必ず確認する。
   - 見積もりに実際の素材を使わないで済むなら、使わない（黒い試験データなど）。
   - 実行後に、使った量や費用の目安を画面に出す。
5. 検査と読み込み。

   ```
   python3 <SKILL>/scripts/check.py <作業フォルダ>
   python3 <作業フォルダ>/server/install.py --dry-run
   python3 <SKILL>/scripts/logs.py --project <作業フォルダ>
   ```

   誤り 0 件を確かめてから導入（Python の部品を入れるときは許可を取って `--with-deps`）、［Load］。
6. 保管庫の動きを試すときは、**使い捨てのキーチェーンだけ**を使い、本物には書かない（AI に任せる作業なら、そう指示する）。試した後、本物のキーチェーンに項目が残っていないか、属性（作成日時）で確かめる。値は読まない（`uc-verify-keychain-test-left`）。

## 確認

利用者の Premiere で次を見てもらいます。

1. 鍵を入れる前に押すと、「鍵が保存されていません」と案内が出る（落ちない）。
2. 鍵を入れると、「保存済み」と出る。鍵の値は画面のどこにも出ない。
3. 実行の前に、「何が外へ送られるか」と「料金の目安」が出て、［実行］を押すまで何も送られない。
4. 結果が返る。プロジェクトに結果が反映される場合は、その内容を目で見て確かめる。AI の出力を無条件に信じない（誤りや作り話を含む）。
5. ネットワークを切る、鍵を消す、の失敗が、日本語の理由で出る。
6. ログ（`logs.py`）に、鍵や、依頼文の全文が残っていない。

## 戻し方

- AI の呼び出し自体は、取り消せません（送った内容と、使った料金は戻りません）。だから実行前の確認が要ります。
- Premiere に反映した結果は、**取り消し 1 回**で戻る作りにします（1 つの取引）。
- 鍵を消す: パネルの［鍵を削除］（サーバーの `delete_secret`）。Mac はキーチェーンアクセスで、サービス名がアプリ名の項目を消してもよい。
- サーバーごと外す: `python3 <作業フォルダ>/server/install.py --uninstall`。

## 使う部品

- `keychain`: `ppm_keychain.py`（鍵の保存・読み・削除。値をログに出さない）
- `local-server`: ジョブの受け渡し、常駐
- `ui-kit`: 鍵の入力欄・確認のダイアログ
