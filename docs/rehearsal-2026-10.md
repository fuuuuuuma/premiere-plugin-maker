# 視聴者役のリハーサル（2026-10-13・0.1.0）

1 本ごとに 1 体の AI（Sonnet）が「利用者の役（台本どおりに答える）」と「作り手の役（SKILL.md のとおりに進める）」を受け持った。Premiere と UXP Developer Tools は動かしていない（「Premiere で確かめる」は利用者に頼む文面まで）。Windows の想定の本は、この Mac で Windows のコマンドを実行せず、出した案内を文章として点検した。
